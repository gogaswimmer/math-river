# Math River v3 — обновление

Новые возможности: зелёная/красная карточка ответа, встроенная цифровая клавиатура для iPad, более детализированные SVG речных рыб. Сохраняются данные и рекорды из v2 (localStorage key `math-river-v2`).

## Обновление через GitHub Desktop
1. В GitHub Desktop создайте ветку `feature/keypad-feedback-fish` от `main`.
2. Откройте папку репозитория через Show in Finder.
3. Замените файлы в корне репозитория содержимым этой папки (не вкладывайте папку внутрь).
4. Сделайте commit и Publish branch.
5. Откройте Pull Request на GitHub, затем Merge pull request.
6. GitHub Pages опубликует изменения из `main`. Подключите iPad к интернету, откройте игру, закройте и откройте снова для обновления service worker.

Проверьте игру на iPad: правильный ответ → зелёный блок; ошибка → красный; клавиатура iOS не открывается; школьный режим и сохранённые жемчужины работают.

Файлы PWA находятся в корне репозитория. Работает на HTTPS и офлайн после первой успешной загрузки.
