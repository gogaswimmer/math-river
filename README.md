# Math River — речной аквариум (PWA v2)

Игра для iPad: русский, українська, Nederlands. Полностью без рекламы и внешних зависимостей.

## Что нового

- Речные обитатели: окунь, плотва, краснопёрка, уклейка, карп, судак, щука, рак, лещ, линь. Иллюстрации условные, нарисованы SVG, а не фотографии.
- Пять действий: сложение, вычитание, умножение, деление, смесь.
- Четыре сложности: легко, средне, сложно, эксперт.
- Тренировка без таймера и школьный тест: 36 примеров за 120 секунд.
- В тесте ответ подтверждается кнопкой или Enter, следующий пример появляется сразу. Пропуска нет; неправильный ответ засчитывается как ошибка.
- Отдельный лучший результат теста для каждой пары «действие + сложность».
- Жемчужины, магазин, анимированный аквариум, статистика и локальное сохранение.

## Математические диапазоны

| Сложность | Сложение/вычитание | Умножение/деление |
|---|---|---|
| Легко | результат в пределах 20 | множители 1–5 |
| Средне | результат в пределах 100 | множители 2–10 |
| Сложно | результат в пределах 1000 | множители 2–12 |
| Эксперт | результат в пределах 10000 | множители 6–20 |

Деление всегда без остатка; вычитание без отрицательных ответов.

## Установка на iPad

1. Распакуйте ZIP на Mac. Внутри папка `math-river`.
2. На GitHub создайте репозиторий (например `math-river`). Загрузите **содержимое** папки `math-river` в корень репозитория.
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
4. Подождите публикации. Адрес будет похож на `https://USERNAME.github.io/math-river/`.
5. Откройте ссылку в Safari на iPad. Подождите загрузки. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
6. Запустите с новой иконки один раз с интернетом. Потом включите авиарежим и проверьте повторный запуск.

Для обновления загрузите новые файлы в **тот же репозиторий**. На iPad один раз откройте игру с интернетом, закройте и запустите снова. Иногда нужно перезапустить её дважды, чтобы активировался новый офлайн-кеш.

**Важно:** данные сохраняются в локальном хранилище конкретной установленной игры. Удаление данных сайта, удаление веб-приложения или смена адреса может стереть прогресс. Если ранее использовали Math Ocean на том же сайте, игра переносит жемчужины и общую статистику из `math-ocean-v1` при первом запуске, но коллекцию старых морских видов не переносит (вместо них теперь речные виды).

## Проверка на Mac

В папке с `index.html` запустите `python3 -m http.server 8000` и откройте `http://localhost:8000/`. Service Worker на localhost работает. Простое открытие `file://` не подходит для проверки офлайн-кеша.

Все файлы локальные, сервер и аккаунт для игры не нужны после установки. Публикация GitHub Pages публичная: исходный код игры будет виден другим, но локальные рекорды не загружаются на GitHub.
